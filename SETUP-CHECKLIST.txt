ANSONS BRANCH INVENTORY — SETUP & DAILY TODO
Plugin by KC Cheng | Requires WooCommerce + Order Delivery Date Pro
================================================================

ONE-TIME SETUP
--------------
[ ] Install WooCommerce (active)
[ ] Install Order Delivery Date Pro (folder must be: order-delivery-date)
[ ] Copy plugin folder to wp-content/plugins/ and activate "Ansons Branch Inventory"
[ ] In Order Delivery Date → Pickup Locations: add all store branches (Manila, Cebu, etc.)
[ ] In WooCommerce → Ansons Branch Inventory → Store code mapping:
        Map POS store codes (e.g. MANILA, CEBU) to each ORDDD branch
[ ] Confirm every online product has a SKU (Products → Edit → Inventory → SKU)
        SKU must match your offline/POS system (e.g. 117600179586)
[ ] Download "WooCommerce SKU template" from Ansons Branch Inventory admin
[ ] Test import with a small CSV, then verify product page + checkout pickup availability

CSV FORMAT (every import)
-------------------------
sku,store_code,status
117600179586,MANILA,available
117600179586,CEBU,not_available

Status values: available  |  not_available

DAILY / REGULAR WORKFLOW
------------------------
[ ] Export or fill CSV for WooCommerce SKUs only (offline-only SKUs not needed)
[ ] Staff marks available / not_available per store branch
[ ] WooCommerce → Ansons Branch Inventory → Import CSV → Merge (daily updates)
[ ] Spot-check a few products on the website (product page + checkout branch selector)
[ ] Review "Last import" for skipped rows and fix store codes or SKUs if needed

MANUAL OVERRIDES (when needed)
-------------------------------
[ ] Products → Edit product → Ansons Branch Inventory meta box
[ ] Set Available / Not available per branch for one SKU
[ ] Update product to save (CSV merge will overwrite matching rows later)
